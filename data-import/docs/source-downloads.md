# 원천 파일 다운로드 기록

수동으로 내려받은 원본 파일의 출처를 기록한다. 원본 자체는 `data/raw/**`에 두며 Git에
포함하지 않는다(재수집 가능한 생성 데이터). **이 문서가 출처의 정본이다.**

파일을 받으면 아래 표에 한 줄 추가한다. 확인하지 않은 값은 추정하지 않고 `미확인`으로
둔다. 실측 결과는 이 문서에 옮겨 적지 않고 해당 Jira 이슈에 남긴다.

API로 수집하는 원천은 여기 적지 않는다. 호출 규칙과 원본 식별자는
[`other-source-survey.md`](other-source-survey.md)가 소유한다.

정적 원본을 Git에 커밋하는 부산 도시철도 계열은 별도로
[`mappings/busan_metro_manifest.json`](../mappings/busan_metro_manifest.json)에서 관리한다.

## 기록 규칙

1. 파일명에 데이터기준일자가 없으면 다운로드 시각을 기준으로 구분한다.
2. 같은 데이터셋을 다시 받으면 행을 덮어쓰지 않고 아래에 추가한다. 이전 배포본과의
   건수·컬럼 차이를 확인할 근거가 사라지기 때문이다.
3. SHA-256은 같은 파일을 다시 받았는지 판별하는 용도다. 전체 값은 파일에서 다시 계산할
   수 있으므로 앞 16자리만 적는다.
4. 인코딩은 추정하지 않고 실제로 디코딩해 확인한 값을 적는다. 표준데이터는 CP949가
   섞여 있어 UTF-8로 가정하면 실패한다.
